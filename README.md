# 🌈 LezVibe v3.0

### The Ultimate Sapphic Energy Scanner

**LezVibe** is a fun, highly-polished web application designed to scan the "vibe" and "energy" of subjects using advanced AI. Inspired by lesbian culture and aesthetics, it delivers a playful, entertainment-focused report on aura, identity, and "the truth."

## ✨ Features

- **📸 Live Bio-Scan:** Use your camera to capture and analyze the vibe of anyone in real-time.
- **🎤 Sonic Signature:** Optional voice recording module to include vocal frequencies in the scan.
- **🧠 AI-Powered Analysis:** Leverages Google's **Gemini 1.5 Flash** to generate creative scan reports.
- **💅 Lesbian Pride Aesthetic:** A beautiful UI designed with the iconic orange-to-pink gradient colors.
- **⚡ Performance First:** Built with Vite and Tailwind CSS for ultra-fast load times.
- **📱 Responsive Design:** Works flawlessly on mobile and desktop.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **AI Backend:** Google Gemini API (@google/genai)
- **Styling:** Tailwind CSS + Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel / Cloud Run

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/alredowanahmed/VibeVerifier.git
cd VibeVerifier
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up Environment Variables
Create a `.env` file in the root directory and add your Gemini API Key:
```env
VITE_GEMINI_API_KEY=your_actual_api_key_here
```

### 4. Run the development server
```bash
npm run dev
```
